#  Bug Tracking & Project Management System - MySQL

A complete advanced relational database project built using MySQL.

##  Tables
- Departments
- Users
- Projects
- Sprints
- Bugs
- Bug Assignments
- Bug Comments
- Bug History
- Notifications
- Attachments
- Test Cases
- Releases

##  Tools Used
- MySQL
- MySQL Workbench

##  Stored Procedures
- Create a new bug
- Assign bug to developer
- Resolve a bug
- Sprint completion report
- Project health report

##  Triggers
- Auto log bug history on every change
- Auto notify developer on bug assignment
- Auto update open bug count per project

##  Queries Included
- All open and in progress bugs by priority
- Developer performance report
- Bug count by priority per project
- Average bug resolution time per developer
- Most critical open bugs
- Sprint completion rate
- Bugs reported per tester
- Project open bug count summary

##  How to Run
1. Open MySQL Workbench
2. Open bug_tracking_system.sql
3. Press Ctrl + Shift + Enter to run
